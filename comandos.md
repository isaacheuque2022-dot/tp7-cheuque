## git init
Convierte una carpeta de la computadora en un repositorio de Git.
## git clone
Copia un repositorio de GitHub a la computadora.
## git status
Muestra el estado de los archivos y que cambios estan preparados para guardar.
## git add
Prepara todos los cambios para el proximo commit.
## git commit
Guarda una versión del proyecto con un mensaje que explica qué cambió.
## git push
Sube los commits nuevos a GitHub.
## git pull
Trae los commits nuevos de GitHub a la computadora.
## git branch
Crea una rama o muestra las ramas que existen.
## git switch
Cambia a otra rama.
## git merge
Une a la rama actual los commits de otra rama.
## git log
Muestra el historial de commits.
